# Развитие Gray Factory

- Использовать одну таблицу SQLite для выдачи `TicketId`. При создании тикета `LEAD` получает уникальный номер без сверки индекса, почты, планов и архива. Тикеты и отчёты остаются Markdown-файлами.
- Связывать тикеты и отчёты обычными Markdown-ссылками. Отчёт ссылается на исходный тикет, а новое поручение — на отчёт, по которому оно возникло. В Obsidian владелец видит всю цепочку работы через обратные ссылки и локальный граф.
- Вернуться к вопросу о Linear после проверки этой схемы в работе. Основание для перехода — конкретная потребность, например общая доска состояний, которую неудобно вести по локальным файлам.
- Перейти к параллельной работе над независимыми тикетами в отдельных рабочих деревьях Git (worktrees). Каждый субагент вносит изменения в своём рабочем дереве. После ревью `LEAD` объединяет изменения и проверяет, что они работают вместе.
