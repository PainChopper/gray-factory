# Агенты проекта

Перед началом работы прочитай [общий роутер](../router.md).

## Корни

- `RUNTIME_ROOT` — `../project-agent-runtime/` относительно каталога, где лежит этот `AGENTS.md`.
- `RULES_ROOT` — каталог роутера по ссылке выше. В путях вида `RULES_ROOT/…` подставляй вместо `RULES_ROOT` этот каталог.

## Настройки проекта

- `DOCUMENT_LANGUAGE` — <язык тикетов, отчётов, планов и заметок>.
